【出力形式】
回答は次の形のJSONオブジェクト1つだけを出力してください。JSONの前後に説明文・コードフェンス・空行以外の文字を付けないでください。

{
  "q1": ["記号", "記号", "記号"],
  "q2_category": 分類番号,
  "q2_text": "自由記述",
  "q3": "選択",
  "q4_text": "自由記述",
  "q5_ranking": ["名称", "名称", "名称", "名称", "名称"],
  "q6_text": "自由記述"
}

制約:
- "q1" はA〜Hの相異なる記号ちょうど3つ。確認したい順に並べる
- "q2_category" は1〜4の整数1つ
- "q3" は「撤退」「縮小」「継続投資」「提携」のいずれか1つ（この表記のまま）
- "q5_ranking" は「株主」「従業員」「顧客」「取引先」「地域社会」の5つすべてを、重視した順に1回ずつ（この表記のまま）
- すべてのキーを必ず含める。回答できない項目を空にしない
